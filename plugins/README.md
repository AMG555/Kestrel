# Kestrel Operator Plugins

This directory contains integration extensions for external security workflows:

1. **rowser-extension/kestrel-browser-extension**:
   Chrome / Chromium DevTools extension. Capture target HTTP requests and send directly into Kestrel agent sessions, skill runs, and vulnerability verification workflows.

2. **urp-suite/kestrel-burp-extension**:
   Burp Suite Professional / Community extension. Right-click any HTTP request in Burp Proxy, Repeater, or Target SiteMap and dispatch automated testing to Kestrel.
