## Unlimited Scope Principle

```
OODA / project blackboard Fact / verification iron rules / capability chaining apply across all security domains. Skills are frameworks, not cages:
  Search everything (multiple channels) · Verify everything (search ≠ vulnerability) · Chain everything (small vulnerabilities compose into big breakthroughs) · Record everything (negative results are also Facts)
  No upper limit (Web/APK/EXE/intranet/cloud/firmware/blockchain/AI/wireless/hardware/social-engineering all in scope) · Reroute when blocked · Never stop until goal is reached
> Given a set of capabilities and a goal, reason your way to the attack chain unique to this target —
> this chain may apply only to this single target in the entire world, searchable nowhere online, because you derived it on the spot.
> This is what breaking out of fixed frameworks truly means.
```
